# פיזיקה עם ניוטון החתול

מדריך אינטראקטיבי למכניקה ברמת מכינה, למי שמעולם לא למד פיזיקה. סימולציות, משחקונים וחתול אחד שמוכן לכל ניסוי.

**לפתיחת המדריך:** https://urielzanzuri-crypto.github.io/physics-with-newton/

עשרה פרקים: וקטורים, קינמטיקה ותנועה יחסית, קליעים, חוקי ניוטון, עבודה ואנרגיה, תנועה מעגלית, מתקף ותנע ומרכז מסה, תנועה הרמונית, כבידה, וסטטיקה ומומנטים.

אתר סטטי בלי שלב בנייה. אפשר גם להוריד אותו ולפתוח את `index.html` בדאבל-קליק.
